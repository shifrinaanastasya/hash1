# Веб-сервис вычисления хэш-функции документов

Веб-приложение для загрузки документов (docx, txt, pdf, rtf), вычисления их SHA256 хэша и извлечения аннотации.

## Возможности

- Загрузка файлов через веб-интерфейс (drag-and-drop или выбор файла)
- Поддержка форматов: DOCX, TXT, PDF, RTF
- Вычисление SHA256 хэша документа
- Извлечение аннотации (первый абзац с 2+ предложениями)
- Отображение даты и времени вычисления по МСК
- Расчёт общего веса (хэш + аннотация) в байтах
- Сохранение результатов в папку `output` в форматах JSON и TXT
- Просмотр и скачивание ранее обработанных файлов

## Структура проекта

```
hash_service/
├── app.py              # Основное Flask-приложение
├── hash_utils.py       # Модуль с функциями обработки документов
├── requirements.txt    # Зависимости Python
├── uploads/           # Папка для временного хранения загруженных файлов
├── output/            # Папка для результатов обработки
└── templates/         # HTML-шаблоны
    ├── index.html     # Главная страница с загрузкой
    ├── result.html    # Страница результата
    └── output_list.html # Список обработанных файлов
```

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. При первом запуске NLTK автоматически загрузит необходимые токенизаторы.

## Запуск

```bash
cd hash_service
python app.py
```

Сервер запустится на адресе `http://localhost:5000`

## Использование

1. Откройте браузер и перейдите на `http://localhost:5000`
2. Перетащите файл или выберите его через диалог
3. Нажмите "Обработать документ"
4. Просмотрите результат на странице с хэшем, аннотацией и статистикой
5. Скачайте результаты в формате JSON или TXT
6. Все результаты сохраняются в папке `output/`

## API эндпоинты

- `GET /` - Главная страница с формой загрузки
- `POST /upload` - Загрузка и обработка файла
- `GET /output` - Список всех обработанных файлов
- `GET /output/<filename>` - Скачивание конкретного файла результатов

## Конфигурация

В `app.py` можно изменить:
- `MAX_CONTENT_LENGTH` - максимальный размер загружаемого файла (по умолчанию 50MB)
- `UPLOAD_FOLDER` - папка для временных файлов
- `OUTPUT_FOLDER` - папка для результатов
